A text from your future self, ten years on: the "quick nap" still eats the whole afternoon, and the dancing never improves.

> It's you from 2036. That 'quick nap' is four hours. Set two alarms — and stop trying to dance, we never learn.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (110 characters, one line, no trailing newline). Set `MAKEFUN_OUTPUT_DIR` to write elsewhere.
